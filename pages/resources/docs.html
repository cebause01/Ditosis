Getting started with Ditosis

High-level docs for integrating Ditosis into your data and ML workflows.

Authentication

Authenticate with API keys generated from your Ditosis dashboard. Include the key as a bearer token in all API requests.

Data generation

Define your dataset configuration (type, schema, distributions) and create a generation job. Ditosis will stream results to your preferred storage destination.

Validation & reports

Every job includes a quality report: distribution matching, diversity metrics, and bias checks. Use these reports to compare experiments over time.
