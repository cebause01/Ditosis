# Ditosis — Synthetic Data Solutions

Modern dark-themed marketing website for Ditosis, a synthetic data company providing high-quality datasets for AI training and fine-tuning.

## Features

- Dark theme with cyan/teal gradient accents
- Fully responsive layout
- Scroll animations and particle effects
- Static site — no backend required
- GitHub Pages ready

## Tech Stack

- HTML, CSS, JavaScript
- Node.js static server (optional, for local dev)

## Local Development

```bash
npm install
npm start
```

Or serve directly:

```bash
python3 -m http.server 8000
```

## Deploy to GitHub Pages

1. Push to `main`
2. Go to **Settings → Pages**
3. Select `main` branch as source

## Structure

```
index.html    Main landing page
pages/        Additional pages
partials/     Reusable HTML partials
assets/       Images and icons
server.js     Optional local dev server
```
